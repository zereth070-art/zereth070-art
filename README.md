## 🛠️ Proyectos destacados

### [PomodoroZion](https://github.com/zereth070-art/pomodorozion) — Spring Boot + WebSocket

App full-stack de temporizador Pomodoro con sesiones, tareas y estadísticas, y
**sincronización en tiempo real entre varios usuarios** por WebSocket.

- **Java 25 · Spring Boot** (Web MVC, Security, Data JPA, Validation, WebSocket)
- **Thymeleaf** + JavaScript vanilla
- **H2** en local · **PostgreSQL (Neon)** en producción
- **Docker** + despliegue en **Render** con auto-deploy desde GitHub
- Autenticación con **BCrypt** y roles, API REST y **tests** automatizados

🔗 **[Demo en vivo](https://pomodorozion.onrender.com/)** · [Ver código](https://github.com/zereth070-art/pomodorozion)

### [PCCOMPONENTES](https://github.com/zereth070-art/pccomponentes) — React + Express + MongoDB

Tienda de componentes de PC con registro, verificación por email y **login social
con Google OAuth 2.0**.

- **React 19 + Vite** · **React Router** · **Zustand** para el estado global
- **Express 5 + Mongoose** sobre **MongoDB**
- **JWT** (Bearer) + **BCrypt** · verificación de email con **Mailjet**
- **Turnstile** (Cloudflare) como capa anti-spam
- **Docker** · variables de entorno por perfil (nada de secretos en el código)

🔗 [Ver código](https://github.com/zereth070-art/pccomponentes)
